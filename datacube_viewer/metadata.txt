about=Load GeoZarr datacubes, plain Zarr stores, NetCDF files and Icechunk repositories
    as raster layers in QGIS.
    Sliders in a dock panel step through the non-spatial axes of the cube (time, sensor,
    etc.) and redraw the layer as you drag. The plugin reads directly from
    plain Zarr v3 stores and NetCDF files as well as Icechunk repositories (local, S3,
    GCS, Azure, R2 or HTTP), resolves the CRS from zarr-conventions "proj:code" or CF
    grid mappings, and switches between pyramid levels as you zoom. Icechunk branches,
    tags and snapshots can be selected at load time and changed afterwards without
    re-adding the layer.
    .
    ONE MANUAL STEP AFTER INSTALL: this plugin needs the "zarr" (>=3) Python package
    for Zarr stores and/or "netCDF4" for NetCDF files, and QGIS's Plugin Manager does
    not install Python packages. After installing, open Raster > Datacube Viewer >
    Install Python Dependencies... - it detects your operating system and QGIS
    build, shows the exact command to run, where to run it, and the interpreter it
    targets, and on Windows, macOS and Linux can run it for you with "Install now".
    That installs with pip --user and pins every package QGIS's Python already has,
    so it never upgrades or replaces one of them. "icechunk" is optional and only
    needed for Icechunk repositories. zarr and icechunk require Python 3.11 or newer.
    On Linux, QGIS uses the system Python, which can be older (Python 3.10 on Ubuntu
    22.04); the README describes using QGIS from conda-forge instead.
    .
    Originally developed by EODC (https://eodc.eu) as "GeoZarr Viewer". MIT licensed.
    This is a renamed fork carrying local changes; it is not the EODC release.
